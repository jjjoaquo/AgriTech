# AgriTech

Proyecto académico de inspección visual de plagas en cultivos. El portal ofrece clasificación experimental de 102 clases con ResNet‑152 y un módulo especializado de espárrago con detección localizada mediante YOLO.

La implementación del MVP, las pruebas y las instrucciones de despliegue están en [mvp](mvp/README.md). El peso ResNet de Alonso se distribuye por separado por su tamaño. El sitio de demostración es [esparragos.comextech.es](https://esparragos.comextech.es/).

La carpeta `docs` conserva el avance previo del equipo con un nombre de archivo compatible con Windows.
